# 🛡️ TgAuth (Telegram Authentication Plugin)

TgAuth — это плагин для серверов Minecraft (Paper 1.21+), который обеспечивает надежную двухфакторную аутентификацию игроков с помощью Telegram-бота. 

## ✨ Особенности
- 🔒 **Связка аккаунтов**: Игроки могут привязать свой Minecraft аккаунт к Telegram с помощью одноразовых кодов (`/reg`).
- 📲 **Авторизация в 1 клик**: При входе на сервер бот отправляет сообщение в Telegram с кнопкой "Да, это я" (InlineKeyboardButton).
- 🛑 **Заморозка до входа**: Неавторизованные игроки получают эффект слепоты, не могут передвигаться и будут кикнуты по истечении времени.
- 🗄️ **Локальная БД**: Данные о привязанных пользователях хранятся в легкой базе данных `SQLite`.

## ⚙️ Требования
- **Ядро сервера**: PaperMC (или форки, например Purpur) версии 1.21.1+
- **Java**: 21+
- **Telegram Bot**: Зарегистрированный бот через @BotFather

## 🚀 Установка для разработки

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_вашего_репозитория>
   cd TgAuth
   ```

2. **Настройте конфигурацию**:
   В целях безопасности файл `config.yml` исключен из репозитория. Перед сборкой вам нужно создать его на основе примера:
   - Скопируйте файл `src/main/resources/config.example.yml` и назовите его `src/main/resources/config.yml`.
   - Откройте `config.yml` и вставьте ваш токен от Telegram-бота.

3. **Сборка проекта**:
   Для сборки плагина со всеми зависимостями (Telegram API) используйте Gradle Shadow:
   ```bash
   # Для Windows:
   gradlew.bat shadowJar
   
   # Для Linux/Mac:
   ./gradlew shadowJar
   ```
   *Готовый плагин появится в папке `build/libs/TgAuth-2.jar`.*

## 🎮 Использование (Команды)
- `/reg` — Сгенерировать код для привязки аккаунта Telegram. Сгенерированный код необходимо отправить в личные сообщения боту.
- `/login` — Команда зарезервирована для входа.

## ⚠️ Безопасность
Никогда не коммитьте свой `config.yml` с токеном от бота в публичные репозитории.
